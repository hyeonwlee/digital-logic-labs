# Digital Logic Labs


## 1. 소개

서강대학교 컴퓨터공학실험Ⅱ(CSE3016) 과목에서 Verilog HDL로 디지털 논리회로를 설계하고 Vivado로 시뮬레이션한 실습 내역을 정리한 저장소입니다.


## 2. 사용 기술

- 언어: Verilog HDL
- 설계 및 시뮬레이션 도구: Vivado
- 하드웨어: FPGA


## 3. 주요 내용

주차별 실습에서 설계한 회로를 기능별로 정리했습니다.
- 기본 논리회로: AND, OR, NAND, NOR, XOR, AOI
- 조합 논리회로: 부울 함수, 비교기, 가산기·감산기, 코드 변환기, 패리티 회로, 디코더·인코더, MUX·DEMUX
- 순차 논리회로: RS 래치, 플립플롭, 카운터, 링 카운터, 시프트 레지스터, 순서 검출기
- 표시 회로: 7세그먼트 디스플레이
- 실습별 Verilog 소스 코드, 테스트벤치 및 시뮬레이션 결과 정리


## 4. 실행 방법

Vivado에서 실습별 Verilog 소스 파일과 테스트벤치를 불러와 시뮬레이션합니다.
